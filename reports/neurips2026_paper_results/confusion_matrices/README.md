# Matched-nuclei confusion matrices

Rows are true types and columns are predicted types in the fixed order: Epithelial, Immune, Stromal, Melanocyte, Other. Each individual fold/seed matrix is preserved as raw counts and row-normalized fractions. The aggregated versions are descriptive sums over repeated observations from both seeds and folds; they are not statistical replicates. PNG renderings are reproducible generated files and intentionally remain outside Git.
